Everything you reach for, nothing you don't

Built for the daily work with real databases: from a quick SELECT to a 300 MB dump on a production server.

Native speed

Rust core, streams tens of thousands of rows in milliseconds. Starts instantly, about 5 MB to download.

SQL editor

Monaco editor with autocomplete for tables, columns and aliases. Run a statement, a selection or the whole script.

Editable grid

Excel-like selection, typed cells, JSON viewer, date pickers. Edits are saved in a single transaction.

Table Doctor

Right-click a table: a health score, what slows it down and a one-click fix for each problem, shown as SQL first. Or check a whole database at once.

Grid filters

Filter any result by column without writing WHERE. Dates, numbers, lists and the most common values, searched in the whole table.

Visual Explain & slow queries

Plans as a tree with the slowest steps highlighted, the queries that hurt a table most, and the index that would fix them.

SSH tunnels

Reach private databases through a bastion. Host keys are pinned and passwords live in the OS keychain.

Production guard

Mark connections as PROD and every write asks for confirmation first. Colored everywhere so you always know where you are.

Parallel import & backups

Load SQL dumps, CSV, Excel and JSON, or back up a whole database to one .sql.gz file. Several connections at once, in the background.

Structure editor

Columns, indexes and foreign keys with an ALTER preview before anything touches the server.

Users & privileges

Create users and roles, grant access to a database, a schema or a single view. See the SQL before applying.

Process monitor

Live sessions and running queries, lock waits and who blocks whom. Cancel a query or kill a connection.

ER diagrams

See every table and relationship of a schema, arrange it, and export one HTML file with the diagram and full table docs for your team.

Move in, in one click

Brings your connections over from DBeaver, pgAdmin, MySQL Workbench, Sequel Ace and .pgpass, with SSH tunnels, folders and saved passwords.

Everywhere, always current

Windows, macOS and Linux, on Intel and ARM. The app updates itself and tells you what's new.

Questions, answered

Is DB Client free?

Yes. DB Client is free and open source under the MIT license. There is no account, no trial and no paid tier.

Which databases does it support?

PostgreSQL and MySQL, including MariaDB. One app for both, with features tuned to each: pg_stat_statements and hypopg on PostgreSQL, performance_schema on MySQL.

Which operating systems does it run on?

Windows 10 and 11 (x64 and ARM64), macOS 11 or newer (one universal build for Apple Silicon and Intel) and Linux x64 and ARM64 as AppImage, .deb or .rpm. It installs for your user without admin rights and updates itself.

How do I find slow queries and missing indexes?

Right-click a table and choose Analyze table. Table Doctor lists the statements that use the table the most, reads their plans and suggests indexes, ready to create with one click. On PostgreSQL with the hypopg extension, What if? shows the cost before and after an index without creating it. Explain shows any plan as a tree with warnings.

Is it safe to use on a production database?

Mark a connection as production and every statement that changes data asks for confirmation first. Fixes are shown as SQL before they run, and Explain Analyze runs inside a transaction that is rolled back. Table Doctor only reads statistics.

Can it connect through SSH?

Yes. SSH tunnels with a password or a private key, with host key verification. Passwords are stored in the operating system's keychain.

Can I bring my connections from DBeaver or pgAdmin?

Yes. DB Client finds the connections saved by DBeaver, pgAdmin 4, MySQL Workbench, Sequel Ace, Sequel Pro and .pgpass and imports them in one click, with SSH tunnels, folders and saved passwords where the tool allows it.

How fast are import and export?

Dumps are split and loaded over several connections at once. In local tests a 300 MB dump loaded 2.4 to 2.5 times faster than psql and the mysql client, and a database backup ran about 5 times faster than pg_dump and mysqldump.
